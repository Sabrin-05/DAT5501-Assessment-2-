Outputs: A series of figures showcasing the results of my data analysis investigation

### Overview
This aim of the analysis is to investigate the effects of socio-economic status and electricity sources carbon dioxide emissions per capita.
Allowing for governments to implement incentives, organisations to change operations to ultimately achieve cleaner, renewable energy.

### Datasets
All three datasets sourced from our world in data 

1. Carbon dioxide emissions per capita
2. Electricity by source
3. World Bank income groups
